# Wivori Trails

Juego móvil independiente de exploración, recolección, comercio y automatización, desarrollado en **Godot 4.4.1**.

**Estado:** prototipo técnico 3D, no versión comercial. La jugabilidad y el acabado gráfico requieren pruebas y mejoras antes de Google Play.

## Próximo paso
El proyecto completo se encuentra en `wivori_bundle.zip`. La tarea de GitHub Actions lo extrae, valida con Godot y genera un APK Android de prueba cuando la compilación termina correctamente.

## Mecánicas implementadas
Movimiento con joystick, cámara con seguimiento y anticipación, agricultura, mochila, ventas, compradores, empleados automáticos, mejoras, expansiones y guardado local.

## Alcance de la prueba
Un APK generado por CI no garantiza una experiencia satisfactoria. Debe revisarse en un dispositivo Android real (rendimiento, gráficos, controles y balance).

El proyecto usa una identidad visual provisional; **Wivori Trails** es nombre de trabajo sujeto a comprobación registral.
